# Disco for Dirigera

**Free disco mode for IKEA DIRIGERA.** Disco for Dirigera is an Android app
that turns the color bulbs on your IKEA DIRIGERA hub (TRÅDFRI color, ORMANÄS
and other color lights) into a synced party light show: Wave, Sync, Random and
Strobe, preset and custom palettes, runs with the screen off, and puts every
light back the way it was when the party ends. Local only, no account, no cloud.

- Website: https://h-s-w.github.io/disco-for-dirigera-site/ (svenska: https://h-s-w.github.io/disco-for-dirigera-site/sv/)
- Google Play: https://play.google.com/store/apps/details?id=com.dirigeraparty
- Privacy policy: https://h-s-w.github.io/disco-for-dirigera-site/privacy.html

Free with 2 lights at a time; Pro unlocks every light with a one-time purchase.
